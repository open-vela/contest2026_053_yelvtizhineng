# 植小伴主业务 API

当前目录为 2026-11-04 运行源码快照，替换比赛仓早期版本。统一安装、运行和测试见 [服务器入口](../README.md)，部署及当前限制见 [部署指南](../../docs/server/部署指南.md)。

包含账号、设备绑定、遥测、照片/语音、AI 问答、观察任务、日记、社区、演示会员/理赔、科普与植物图鉴、管理台、MQTT 管理和 OTA 文件发布接口。社区、会员/理赔和验证码仍含参赛演示逻辑，不能视作真实短信、支付或保险业务。

新增科普与图鉴入口为 `/api/v1/learning/`；新版 PWA 的 `index.html` 引用 `app-growth-20261104.js`、`catalog.js` 和 `growth.css`。旧 `app.js` 保留，供缓存版本过渡。BOX 的独立语音/图像路由在兄弟目录 `box_ai`，由反向代理分流。

程序启动会创建自己的数据库表和演示种子数据。源码中的默认演示验证码 `123456` 和默认签名口令仅供本机开发；真实部署使用环境变量，仓库不包含线上配置。运行时目录 `data/`、`ota/` 不入库。

管理台密码仅从 `PLANT_ADMIN_PASSWORD` 读取，未配置时拒绝登录。旧串口透传网关及其绑定时自动注册逻辑已移除；新传感器先注册，再绑定账号并配置独立设备令牌。
