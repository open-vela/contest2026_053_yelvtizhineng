# 服务器源码来源与验证范围

整理日期：2026-11-04。源码从运行服务器读取并逐文件 SHA256 核对；采集过程中不重启、不部署、不改写线上服务、用户数据或设备绑定。源文件与整理版本的对应表见 [source_provenance.json](source_provenance.json)。服务拆分与目录整理不代表重新实现了这些业务逻辑。

此次覆盖主 FastAPI 应用与静态前端、科普和植物图鉴、BOX 独立服务/标准语音/快速视觉/指定土壤源绑定/FAQ 检索，以及 ESP32 无线土壤节点的 JSON MQTT 网关。题库保留逐条来源和许可；大型运行时 SQLite 由源数据重建。

已排除线上环境文件、实际设备共享映射、设备令牌、用户数据库、媒体、缓存、采集日志、模型权重、调试目录和服务器历史备份。旧部署说明中的线上验证码没有沿用。原始只读快照与本机核对材料留在本机，不上传。

新版 PWA 静态资源与服务器源码一并更新；Android 原生工程及设备固件不在此次更新范围。原有 AI Coding 日志不改写，本次也不把整理摘要冒充新的原始开发日志。

独立目录的最终测试结果记录在 [validation.json](validation.json)。其中只覆盖本次实际执行的测试；不代表已经在全新服务器完成公网部署、真实模型计费调用、MQTT Broker/TLS 实连或硬件端到端验收。只读线上健康检查与隔离测试分别记录。

公开版本额外移除了退役透传链路、默认管理密码、展示页联系电话及含联系电话的海报图片；网关管理切换为 JSON 服务并限制配置回传。这些调整记录为公开版本适配，不声称与运行服务逐字节完全相同。线上服务不因本次代码发布而改变。

旧传感器的固定序列号共享接口和跨节点在线状态推断已一并移除；JSON 节点遥测仅更新当前设备的在线时间，BOX 土壤读取仍按显式设备绑定查询。
