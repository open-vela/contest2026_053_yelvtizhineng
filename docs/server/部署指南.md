# 服务器端部署指南

## 部署映射

三个服务对应 `server/README.md` 的目录。示例路径沿用已核对的运行布局：将 `server/plant_server` 放到 `/opt/plant_server`，`server/box_ai` 放到 `/opt/plant_box_voice_20261031`，`server/soil_gateway` 放到 `/opt/plant_soil`。不要将示例直接覆盖正在使用的工程或数据库；在自己的新目录先完成验证。

主服务与 BOX 共用主服务虚拟环境。安装 `server/requirements.txt`；网关的 `/opt/plant_soil/venv` 也需 `paho-mqtt` 和 `requests`。执行题库重建脚本，在 BOX 目录生成 `qa_bank_v490_20261103.sqlite3`；运行准备脚本将主题库复制到目标数据目录，已有文件保留。复制部署到 /opt 时应先在仓库内准备数据，再保留生成结果，或在目标目录运行 `python tools/prepare_runtime.py --plant-server /opt/plant_server --box-ai /opt/plant_box_voice_20261031`（tools 脚本须保留在完整 server 目录结构中）。

## 配置与启动

1. 将 `server/deploy/plant-server.env.example` 填写后存到 `/etc/plant-server.env`。生成独立签名口令、管理密码，配置自己的模型服务密钥。主服务和 BOX 必须使用同一个 `PLANT_TOKEN_SECRET`、同一套业务数据库路径。
2. 将 BOX 配置填入 `/etc/plant-box-ai.env`，填写实际已注册的设备 ID 白名单。土壤绑定 JSON 从 `server/box_ai/soil_bindings.example.json` 的空字典开始，确认共享关系后自行添加；不要复制现场其他用户的绑定。
3. JSON 网关使用 `/opt/plant_soil/json_bridge.env`，参考 `soil-json.env.example` 模板。按设备配置令牌、MQTT 账号、TLS/CA、主题及 API 地址。
4. 创建 `/opt/plant_server/data/logs`、网关队列父目录和主服务媒体子目录后，复制需要的 `.service.example` 为 `/etc/systemd/system/` 下相应服务名，核对解释器路径、环境文件权限和运行用户。BOX 的只读沙箱沿用原服务设计，须在启动前准备目录、题库和数据；开启写缓存的功能需要另行评估只读约束。
5. 在自己的环境执行 `systemctl daemon-reload` 并按需启动主服务、BOX 和 JSON 土壤网关。传感器采集周期在节点配网页面设置，管理台不再下发串口读取指令。
6. 在自己的 HTTPS 虚拟主机中参考 `nginx-locations.conf.example` 分流：`/api/v1/box/` → 9012，其余业务/PWA/管理页 → 8011。示例不包含生产域名、证书或完整公网加固配置。

仓内只提供模板，不自动改动现有服务器。主服务管理台包含本机 systemctl/Mosquitto 配置管理；本次网关管理已切换到 JSON 服务，仅返回配置白名单，移除了旧透传参数和环境文件回传。这些操作依赖额外系统权限，普通服务用户不具备时相应管理操作不可用。公开 API 可用性不等于已验证所有运维管理功能。

## 演示与可选依赖

默认验证码、会员、理赔等逻辑仍用于参赛演示，没有接入真实短信、支付或保险系统。关闭验证码回显不等于已经接入真实短信通道。对外发布前应按实际产品需求完善这些能力。

主服务 mock 模式可用于本机端到端演示。BOX 严格要求真实模型配置和设备白名单；测试中对模型调用做隔离替代，不声称完成新的付费模型/硬件联调。

M5 视觉场景记忆可选依赖为 `plant_server/requirements-m5-vision.txt`，当前代码还从数据目录查找 `vision_models/face_detection_yunet_2023mar.onnx`。模型权重、音频、用户照片、OTA 固件和展会介绍视频不属于此次源码包，须按原始来源/许可在自己的部署中准备。缺少可选资源时不要把相关功能宣称为完成验证。

## 验证入口

本机 `GET /api/v1/health`、`GET /api/v1/box/health` 是只读健康检查。不要把 `/api/v1/ai/health` 当作零成本检查：现有实现可能真实调用模型。学习/图鉴、鉴权隔离、MQTT 持久队列及 FAQ 索引自测见服务器入口的命令。
