# 依赖与源码来源

| 依赖 | 来源及用途 |
| --- | --- |
| openvela / NuttX | 官方 `open-vela/nuttx`，内核、网络、驱动与板级基础 |
| NuttX apps | 官方 `open-vela/nuttx-apps`，NSH、WAPI、DHCP、NTP、MQTT-C 包装 |
