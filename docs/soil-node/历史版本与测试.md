# 版本与测试说明

本包是 2026-11-01 最后烧录的 Wi-Fi 等待卡死修复版，2026-11-04 核对并打包。

## 已合入的修复

1. SoftAP 在启动前同步初始化配置缓存，避免异步 AP 启动时复制零客户端上限，引发手机“网络拒绝接入”。
2. SoftAP 启停时设置/清除 carrier 状态，保证 DHCP 和 HTTP 能正常发包，解决连接后停在获取 IP 的问题。
3. 配网窗口延长至 15 分钟；手机浏览器需显式访问 HTTP。
4. 新增独立设备身份与云端主题，初始未保存 SSID 时仍保留已有云端凭据。
5. Wi-Fi 联网、DHCP 和 AP 操作改用网络库接口，移除应用层短命令的 posix_spawn/waitpid 包装。

## 本次停报的现场证据

15:28:21 停报后，重新接入 USB、尚未复位时，节点 shell 可响应，运行时间约 31 分钟，soil_node 等待信号量。调用栈位于 soil_wifi_join -> run_builtin -> waitpid -> nxsched_waitpid，返回地址指向 ifdown wlan0 调用之后；任务列表没有对应命令子任务。

因此确认了网络命令等待卡死，不能将该现场简单归因于电池断电。底层内核竞态的精确触发时序没有独立复现，本版通过移除该应用调用路径修复。
