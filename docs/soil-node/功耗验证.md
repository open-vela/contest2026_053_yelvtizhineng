# 功耗与稳定性验证

周期深睡已经在历史样机测试中工作；当前未完成校准电流仪实测，也未完成修复版长期纯电池续航验证，不填写待机电流或续航天数。

实测时记录供电电压、温度、真实探头负载，使用至少 1 kHz 的电流记录仪，覆盖不少于五个完整周期。分别测量 60 秒和 300 秒上报间隔，按串口的 `CYCLE_ACTIVE_MS`、`DEEP_SLEEP_US` 划分完整周期，积分电流计算周期电荷和平均电流。探头单独供电时必须分别记录，不能仅以主控电流代表整机。

```bash
python3 tools/soil-node/power_trace_analyze.py current.csv \
  --start-s 10 --end-s 310 --cycles 5 --cycle-seconds 60 \
  --battery-mah 2000 --usable-fraction 0.8 --output power-result.json
python3 -m unittest discover -s tools/soil-node -p 'test_*.py' -v
```

分析器输出积分结果和容量假设下的估算；估算不替代真实长时间放电测试。稳定性还需覆盖断网、Broker 不可用、错误凭据、拔掉探头、配网后重启和固件升级保留配置。
