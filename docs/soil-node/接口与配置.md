# 无线土壤节点接口与配置

Modbus 请求：`02 03 00 00 00 08 44 3F`。响应 21 字节：地址、功能码 03、数据字节数 16、八个大端寄存器及 CRC16/MODBUS（低字节在前）。以 `soil_sensor.c` 的解析为准；帧长、从站地址、功能码和 CRC 不通过时不上报本次采样。

MQTT JSON 字段为 `moisture`、`temp`、`ec`、`ph`、`salt`、`nitrogen`、`phosphorus`、`potassium`。温度（有符号）、水分、pH 原始值除以 10；EC、盐分及 NPK 保留探头原值。量程与物理单位应以实际探头说明书和校准为准。

`soil_cloud_config.h` 保留已验证样机的 Broker、端口、Client ID、设备 ID 及主题，不包含密码。该项目的 **1883 端口实际使用 TLS**，不能按常见端口惯例当作明文连接。启用 CA 和主机名验证，根证书为 ISRG Root X1；NTP 校时用于证书有效期检查。

每台新增节点需分配独立设备 ID、Client ID、MQTT 主题和凭据，重新构建后再部署。不要复制同一身份到多台节点。凭据由配网页面录入 LittleFS `/data/soil.cfg`，不得提交该文件、完整 Flash、私钥或现场密码。

| 配网页面接口 | 行为 |
| --- | --- |
| GET / | 手机配网页面 |
| GET /api/scan | 附近 Wi-Fi |
| GET /api/settings | 当前配置及凭据是否已设置 |
| GET /api/status | 最近采样和上报状态 |
| POST /api/save | 验证、保存配置 |
| POST /api/reset | 清除配置并重启配网 |

可配置上报周期 10–3600 秒、地址 1–247、波特率 4800/9600/19200/38400、温度偏移 ±20.0、pH 偏移 ±5.0。默认地址 2、9600、60 秒、省电开启。上述范围来自当前固件校验逻辑，并不代表探头支持所有波特率。
