# 02 · 硬件与接线

## 一、硬件清单（参赛样机）

| # | 物料 | 规格 | 数量 | 作用 |
|---|------|------|------|------|
| 1 | 主控开发板 | **CHD-ESP32-S3-Box**（ESP32-S3，16 MB Flash，Octal PSRAM 80 MHz） | 1 | 主控 + 显示 + 音视频一体 |
| 2 | 土壤传感器 | **RS485 八合一**（温度 / 水分 / EC / pH / 盐分 / 氮 / 磷 / 钾），Modbus RTU | 1 | 核心感知 |
| 3 | RS485 转 TTL 模块 | 3.3 V 供电，自动收发方向 | 1 | 电平与总线转换 |
| 4 | 锂电池 + 充电管理 | 3.7 V 化学体系 | 1 | 便携演示 |
| 5 | microSD 卡 | FAT32 | 1 | 配置持久化与素材 |
| 6 | 连接线材 / 外壳 | — | 1 套 | 装配 |

## 二、引脚分配（取自板上实际生效的 `.config`）

### 2.1 土壤传感器（RS485 → UART0）

| 信号 | 芯片引脚 | 配置项 |
|------|---------|--------|
| UART0 TX | **GPIO42** | `CONFIG_ESP32S3_UART0_TXPIN=42` |
| UART0 RX | **GPIO40** | `CONFIG_ESP32S3_UART0_RXPIN=40` |
| 波特率 | 9600 8N1 | `SOIL_SENSOR_BAUD_DEFAULT` |
| 设备节点 | `/dev/ttyS0` | `SOIL_SENSOR_DEV_DEFAULT` |
| Modbus 从站地址 | `0x02` | `SOIL_SENSOR_ADDR_DEFAULT` |

### 2.2 摄像头（OV3660 / DVP）

| 信号 | 说明 |
|------|------|
| VSYNC | **GPIO42** |
| Y9 | **GPIO40** |

> ⚠️ **这两根线与土壤传感器的 UART0 是同一组** —— 见 2.6 互斥说明。

### 2.3 音频（I2S0，主模式，16 bit / 24 kHz）

| 信号 | 芯片引脚 | 配置项 |
|------|---------|--------|
| MCLK | **GPIO2** | `CONFIG_ESP32S3_I2S0_MCLKPIN` |
| BCLK | **GPIO17** | `CONFIG_ESP32S3_I2S0_BCLKPIN` |
| WS（LRCK） | **GPIO45** | `CONFIG_ESP32S3_I2S0_WSPIN` |
| DIN（采集，来自 ES7210） | **GPIO16** | `CONFIG_ESP32S3_I2S0_DINPIN` |
| DOUT（播放，送往 ES8311） | **GPIO15** | `CONFIG_ESP32S3_I2S0_DOUTPIN` |

I2S0 同时开 RX 与 TX（`CONFIG_ESP32S3_I2S0_RX/TX=y`）。

### 2.4 SD 卡（SDMMC）

| 信号 | 芯片引脚 | 配置项 |
|------|---------|--------|
| CLK | **GPIO43** | `CONFIG_ESP32S3_SDMMC_CLK` |
| CMD | **GPIO0** | `CONFIG_ESP32S3_SDMMC_CMD` |
| D0 | **GPIO44** | `CONFIG_ESP32S3_SDMMC_D0` |

> 注意：配置里只用了 **D0 一根数据线（1-bit 模式）**，这是 SD 写入只有 ~23.5 KB/s 的可能原因之一
> （见 `README` 第九节"已知限制"）。语音链路已改为不落卡，绕开了这个瓶颈。

### 2.5 显示与触摸、电池

| 项 | 说明 | 配置项 |
|----|------|--------|
| LCD | ST7796（板载屏），板级选 `CONFIG_ESP32S3_BOX_LCD=y` | — |
| 触摸 | `/dev/input0` | `CONFIG_ESP32S3_BOARD_TOUCHSCREEN_PATH` |
| I2C | 板级 I2C（触摸 / codec 控制） | `CONFIG_ESP32S3_BOARD_I2C=y` |
| 电池电压 | ADC1 通道 0，衰减 3.1 V 档 | `CONFIG_ESP32S3_ADC1_CHANNEL0` / `CONFIG_ESP32S3_ADC_VOL_3100` |

电量标定：**3.3 V 计为满电**，3.7 V 为电池化学上限（满电显示 100%，不再按 4.2 V 锂离子口径计算）。

### 2.6 ⚠️ 引脚互斥（最容易踩的坑）

`GPIO42 / GPIO40` 被**摄像头 DVP** 和**土壤传感器 UART0** 共用：

| 使用方 | GPIO42 | GPIO40 |
|--------|--------|--------|
| 摄像头 DVP | VSYNC | Y9 |
| 土壤传感器 UART0 | TX | RX |

**不能同时用**。固件里的互斥序列：

```
进拍照页 → 停 3s 轮询 → soil_sensor_set_paused(true)
        → 完整关闭摄像头硬件（释放 DVP 推挽输出）
离拍照页 → esp32s3_uart0_reclaim_pins() 把 GPIO42/40 路由回 UART0
        → soil_sensor_set_paused(false) → 恢复轮询
```

若自行动手改线，**不要**把土壤传感器接到别的 UART 上却仍让摄像头占用这两根线，
两边会互相驱动、读出乱码。

## 三、接线步骤

1. **断电**作业，先接传感器再接电。
2. RS485 模块的 A/B 接到土壤传感器对应端子；VCC 3.3 V、GND 共地。
3. RS485 模块的 TTL 侧 TX → 板卡 **GPIO40（RX）**，RX → 板卡 **GPIO42（TX）**。
4. 插入 microSD 卡（FAT32）。
5. 接电池（或在 USB 供电下先用 Type-C 调试）。
6. 上电，屏幕应显示开机横幅 `=== Firmware V1.3.0 ===`。

## 四、上电自检

| 检查项 | 期望现象 | 若不符 |
|--------|---------|--------|
| 屏幕 | 亮起并进首页，顶部有时间/日期/电量/网络 | 检查背光与板级 LCD 配置 |
| 传感器 | 首页/数据页出现八参数真实值 | 控制台跑 `plant soil scan` 排查接线 vs 地址/波特率 |
| 摄像头 | 进拍照页能取景 | 确认离开拍照页后传感器轮询已恢复 |
| 音频 | 能录音、能出声 | 检查 I2S 引脚与 codec 供电 |
| 网络 | 顶部出现信号图标 | 屏幕「网络设置」页扫描选网（**只支持 2.4G**） |
| 服务器 | `plant srv status` 显示已连 | 检查 `/mnt/sd/plant.cfg` 里的 `server_host` |

## 五、串口控制台的注意点

板卡控制台走芯片**内置 USB 串口**。

> **打开串口却不读数据，会拖住板卡输出**（表现为点屏幕卡住、扫描网络半天不出结果）。
> 本版已把驱动从无限等待改成**限时等待 200 ms + 超时丢弃积压**来缓解，但仍建议不必要时别占着串口。

用 Python 打开串口做自动化时，务必先把 DTR/RTS 置低，否则会触发板卡复位：

```python
import serial
s = serial.Serial()
s.port = "COM3"; s.baudrate = 115200; s.timeout = 0.05
s._dtr_state = False; s._rts_state = False
s.open()
```
