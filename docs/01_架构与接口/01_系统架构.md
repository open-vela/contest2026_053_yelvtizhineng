## 二、三端角色与运行的系统

| 节点 | 运行的系统 | 角色 |

| 板卡（ESP32-S3 Box） | **openvela / NuttX** | 感知节点 + 交互终端 + 执行节点（取走养护单并回执） |

## 四、关键流程

### 4.1 采集与展示

```
Modbus 轮询(3s) → soil_data_s 缓存 → 订阅者刷新（首页 4 项 / 数据页 8 参数）
                                  → 每 30s 节流上云 → 云端落库 → 手机端展示
```

### 4.2 拍照诊断

```
「拍一拍」→ 摄像头取帧(640×480) → 上传 /api/v1/ai/image
   → MiMo 图像理解 → JSON（品种/阶段/健康/建议）→ 诊断页渲染 → 存成长日记
```

### 4.3 语音对话（本版重点优化）

```
按下说话 → 边录边传（1.5s 静音收尾 / 上限 5s）
   → 服务器 finalize：ASR → 大模型 → TTS
   → 板卡流式接收音频，边下边播（16 kHz）
   → 气泡显示转写 + 回答
```

**优化前后对比**

| 阶段 | 优化前 | 优化后 |
|------|-------|-------|
| ASR 转写 | 0.69 s | 0.69 s |
| 大模型生成 | 5.98 s | 2~6 s（限长 + 关思考） |
| TTS 合成 | 2.83 s | 2.83 s（音频变短后同步下降） |
| 音频下载 | **33.80 s**（795 KB @ SD 卡 23.5 KB/s，瓶颈） | 与播放重叠，不再单独等待 |
| **说完话到出声** | **≈43 s** | **≈6~8 s** |

根因与手段：
- 瓶颈不是网络（板卡→云 ping 30~40 ms、单次 HTTP 往返 0.14 s），而是**语音回复先落 SD 卡**（实测写入仅 23.5 KB/s）。
- 手段一：**边下边播** —— 顺序解析 WAV（不 seek，头可跨包），边收边写 I2S，完全重叠。
- 手段二：**音频瘦身** —— 只念回答不念转写、限长 120 字、24 kHz 降采样到 16 kHz。

### 4.4 心跳与在线判定

```
板卡 60s 心跳 → 云端更新 devices.status / last_seen_at → 管理台与手机端展示
换网后即便错过注册，也能靠心跳自愈补注册
```

### 4.5 执行回路

```
服务器生成养护动作 → 下单 → 板卡下次同步取走 → 界面点一下即完成 → 回执写回成长日记
（继电器尚未接入，当前为干跑形态；接入后沿用同一套执行器接口）
```

## 五、端云职责划分

| 职责 | 端侧（板卡） | 云端 |
|------|------------|------|
| 采集 | RS485 八参数轮询、摄像头取帧 | — |
| 评估 | 阈值规则评语（**离线可用**） | 大模型诊断与建议 |
| 交互 | UI、录音、播放、气泡 | 转写、生成、合成 |
| 存储 | SD 配置与素材缓存 | SQLite 落库与归档 |
| 下发 | 取单、执行、回执 | 生成养护单、执行器编排 |

**为什么不把大模型放端侧**：ESP32-S3 的内存与算力不足以承载识别与生成模型。
本作品采取"**AI 在云、实时性与降级在端**"的分工，是资源受限硬件上更稳的方案。

## 六、断网 / 弱网降级策略

| 场景 | 端侧行为 | 云端行为 |
|------|---------|---------|
| 外网断 | 界面显示离线；本地阈值规则仍给评语；数据先缓存 | 大模型不可用时走降级链与占位回答，服务不崩 |
| 局域网断 | 心跳重连；配置持久化在 `/mnt/sd/plant.cfg` | 设备状态转 offline，恢复后自愈补注册 |
| 换 Wi-Fi 环境 | 屏幕「网络设置」页扫描 SSID、输密码即连 | 换网后靠心跳补注册，无需重启服务 |
| 模型返回空/占位 | 板卡侧识别到无有效音频则走兜底播放 | 自动关思考重试 → 备用模型 → 占位兜底 |

## 七、引脚互斥设计（重要）

摄像头 DVP 的 `IO42(VSYNC) / IO40(Y9)` 与土壤传感器使用的 `UART0` **复用同一组物理线**。

互斥序列：

```
进拍照页  → 停 3s 轮询（join 轮询线程）→ soil_sensor_set_paused(true)
          → 完整关闭摄像头硬件，释放 DVP 输出
离拍照页  → esp32s3_uart0_reclaim_pins() 把 IO42/IO40 路由回 UART0
          → soil_sensor_set_paused(false) → 恢复 3s 轮询
```

从机制上杜绝两条数据流对撞。
