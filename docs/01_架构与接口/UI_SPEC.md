# 植小伴 · 虫洞嵌入式端 UI 原型规格（UI_SPEC）

> 目标硬件：ESP32-S3-BOX · OpenVela (NuttX) · LVGL v9.1 · 3.5" 480×320 RGB565 触摸屏
> 目标用户：小朋友（识字量少/不识字），交互以 emoji 大图标 + 语音为主
> 本文档是 UI 界面需求的唯一事实来源，配套《ARCHITECTURE.md》描述目录/产品/代码架构。

---

## 0. 设备与运行环境

| 项 | 值 |
|---|---|
| 分辨率 | 480×320（横向） |
| 色深 | RGB565（`LV_COLOR_DEPTH 16`，仓库 lv_conf_template 默认值） |
| LVGL | v9.1（`apps/graphics/lvgl/lvgl`，`LVGL_VERSION_MAJOR 9`） |
| 输入 | GT911 电容触摸（I2C1，`LV_USE_NUTTX_TOUCHSCREEN=y`） |
| 输出 | ST7789V/ST7796 480×320（SPI2，`LV_USE_NUTTX_LCD=y`，双缓冲） |
| 系统 | NuttX NSH 启动 `plant` 程序，主线程创建 LVGL 任务 |
| 字体 | 中文需启用 CJK 字体（内置 `lv_font_simsun_16_cjk`，16px 常用汉字子集）；标题/大数字用 Montserrat 系列 |
| 传感器 | RS485 Modbus RTU 7合1（温度/水分/EC/盐/N/P/K/pH） |
| AI | MiMo API（文本 + 图像），摄像头 OV3660 |

## 1. 屏幕总览

**交互**：
- 点 🪴 → ② AI拍照；点 🎙️ → ⑥ 语音对话
- 点 4-Tab 切换 ①④⑤⑦；点植物卡片 → ④ 数据页

**要点**：

## 3. 设计系统（Design Tokens）

### 3.1 色彩规范（每页一个主题色）

| Token | 值 | 用途 |
|---|---|---|
| `CLR_PRIMARY_GREEN` | `#16a34a`（深）/ `#4ade80`（浅） | 主绿：首页/日记主色、✅ 成功、主按钮 |
| `CLR_DATA_BLUE` | `#3b82f6` | 数据蓝：数据页、识别/诊断页 |
| `CLR_TASK_YELLOW` | `#f59e0b` | 任务黄：任务页、徽章 |
| `CLR_VOICE_PINK` | `#ec4899` | 语音粉：语音页、🎙️ 按钮 |
| `CLR_BG_GRAD_A/B` | 浅绿→浅蓝（如 `#e8f5e9`→`#e3f2fd`） | 页面背景渐变（自然绿意） |
| `CLR_CARD_BG` | `#ffffff`（85% 不透明） | 卡片底色 |
| `CLR_TEXT_MAIN` | `#1f2937` | 主文字 |
| `CLR_TEXT_SUB` | `#6b7280` | 次要文字 |
| `CLR_STATE_OK/WARN/BAD` | `#22c55e` / `#f59e0b` / `#ef4444` | 🟢🟡🔴 状态点 |

- **鲜艳但不刺眼**：每页只用一个主题色做强调，其余用中性色 + 状态色。
- 渐变背景：LVGL v9 支持 `lv_obj` 背景渐变（`lv_style_set_bg_grad_color` + 方向），页级容器设置即可。

### 3.2 圆角与间距

- 卡片圆角：**14–20px**（`lv_style_set_radius`），大卡片 20，小卡片/按钮 14。
- 页面边距 16px；卡片间距 12px；卡片内边距 16px。
- 状态栏高 40px；底部导航高 64px；内容区自适应 flex。

### 3.3 字体（儿童友好，大字号）

| 用途 | 建议 |
|---|---|
| 中文正文/按钮 | CJK 字体：内置 `lv_font_simsun_16_cjk`（16px）起步；如需更大中文，用 `lv_font_conv` 生成 20/24px 常用字子集（UI 用字全集见 §5） |
| 英文/数字（数值、进度环中心） | `lv_font_montserrat_28/36`（大数字醒目） |
| 标题 | Montserrat 20 + 中文 20px 混排 |
| emoji | 用 LVGL 图像资源（PNG→C 数组）替代系统 emoji 字体，保证跨设备一致 |

- defconfig 当前只开了 `LV_FONT_MONTSERRAT_20`；需按需开启 `LV_FONT_MONTSERRAT_28/36` 与 `LV_FONT_SIMSUN_16_CJK`。

### 3.4 图标策略

- **一律用图片资源**（`lv_image` + 转成 C 数组的 PNG/SVG），不用系统字体符号，保证「不识字的幼儿也能看懂」且渲染一致。
- 建议图标集：状态栏（🌵🔋☀️）、数据卡（💧🔥☀️⚗️）、导航（🏠📊✅📖）、动作（🪴🎙️📷←）、状态（🟢🟡🔴）、心情（😊🥱😢）、成就（🏅🎖️）、日记（📖🌱💧）。

### 3.5 动画（克制，适配 RTOS 性能）

| 动画 | 位置 | 实现 |
|---|---|---|
| 扫描线 | ② 拍照取景框 | `lv_anim` 平移半透明横线（LVGL 暂停期间由摄像头任务自绘） |
| 语音波形 | ⑥ 语音页 | `lv_anim` 驱动 5-8 条线高度 |
| 完成打勾 | ⑤ 任务完成 | `lv_anim` 缩放/淡入（≤200ms） |
| Tab 切换 | 全局 | 无过渡或 150ms 淡入（可选） |

> 原则：同一时刻至多 1 个全屏动画；动画回调里不分配内存；`LV_USE_ANIMATION` 开启但动画总数受限。

## 4. LVGL v9 适配要点（移植注意事项）

1. **双缓冲与摄像头直写冲突**：`CONFIG_LV_NUTTX_LCD_DOUBLE_BUFFER=y` 时 LCD 帧缓冲由 NuttX LCD 驱动管理；②拍照页「跳过 lv_timer_handler 直写 LCD」意味着进入该页时暂停 LVGL 渲染循环（`lv_timer_pause` / 标志位），由摄像头任务直接 `lcd` 设备写帧，退出时恢复并强制全刷新（`lv_obj_invalidate` / `lv_refr_now`）。两套写路径必须互斥（同一帧缓冲）。
2. **RGB565**：`LV_COLOR_DEPTH 16`；图标/照片转换时用 RGB565 格式，避免运行时转换开销。
3. **中文字体**：LVGL v9 无系统中文 emoji 字体；中文正文用 `lv_font_simsun_16_cjk` 或自定义子集字体；**禁止**用 Montserrat 渲染中文。
4. **布局**：优先 `LV_FLEX` / `LV_GRID`（v9 内置，无需额外 Kconfig），比绝对坐标适配性强；480 宽可按 4 列 flex 排数据卡。
5. **对象复用**：实时数据刷新只 `lv_label_set_text` / `lv_chart_set_next_value`，不删除重建对象（避免碎片与闪烁）。
6. **主题**：用 `lv_theme_default_init` 定制色板（primary = 主绿），再逐对象覆盖 token；或自建轻量 `lv_theme`。
7. **内存**：ESP32-S3 双缓冲 480×320×2B×2 ≈ 600KB 需外部 PSRAM 或降为单缓冲 + 部分刷新（`LV_DRAW_SW`）；图标 C 数组尽量 `const` 放 flash。
