# 04 · 云平台运行与部署

> 形态：**FastAPI + SQLite**，单进程同时提供接口、管理台与手机端页面，默认端口 **8011**
> 代码：`server/plant_server/`（与云端 `/opt/plant_server` 逐字节一致）

---

## 一、这是什么

植小伴的"大脑"。板卡采集上来的传感器数据与图像在这里落库，AI 对话、看图诊断、
语音转写与合成由它统一调用大模型，网页管理台和手机端（PWA）也由它一起发出去。

| 面 | 地址 | 说明 |
|----|------|------|
| 设备 / App 接口 | `/api/v1/…` | **89 个路径 / 94 个操作**（openapi 口径） |
| 网页管理台 | `/admin/` | 服务器状态、设备、用户、理赔、内容管控 |
| 手机端 | `/mobile/` | 手机浏览器打开即用，可"添加到主屏幕" |
| 接口文档 | `/docs`、`/openapi.json` | Swagger 可直接试 |

---

## 二、本机运行（最快路径，不需要硬件）

```bash
cd server/plant_server
pip install -r requirements.txt
python -m app.services.service_ctl --start --port 8011
# 或（注意 run_server.py 的默认端口是 8000，要显式指定）
python run_server.py --port 8011
```

依赖：Python 3.10+（本机开发用 3.11 / 云端 3.10 均可）、`fastapi` / `uvicorn[standard]` / `requests` / `pillow`。

启动后打开：

```
http://127.0.0.1:8011/admin/     ← 网页管理台（口令由环境变量 `PLANT_ADMIN_PASSWORD` 设置）
http://127.0.0.1:8011/mobile/    ← 手机端（浏览器调到手机尺寸更好看）
http://127.0.0.1:8011/docs       ← 接口文档
```

### 演示账号与登录

默认开启演示模式（`PLANT_DEMO_OPEN=1`）：

| 项 | 值 |
|----|----|
| 短信验证码 | **固定 `123456`**（`PLANT_DEMO_CODE`） |
| 验证码回显 | 开启（`PLANT_DEMO_SMS_ECHO=1`），接口直接把码返回，方便演示 |
| 一键演示登录 | 开启 |

> 生产环境请把 `PLANT_DEMO_OPEN=0`、`PLANT_DEMO_SMS_ECHO=0` 并接真实短信通道。

### 没有大模型密钥会怎样

**不会崩**。未配置 `PLANT_MIMO_KEY` 时自动进入 **mock 演示模式**，
启动日志会打印 `[AI] 演示模式（mock）`，界面流程全部可走通，只是回答是预置内容。

要接真实模型（小米 MiMo）：

```bash
export PLANT_MIMO_KEY=<你的密钥>          # 必填；缺失即 mock
export PLANT_AI_MODE=auto                 # auto（默认）/ mimo（强制真实）/ mock（强制演示）
export PLANT_MIMO_MODEL=mimo-v2.5          # 多模态主模型（看图 / 听音）
export PLANT_MIMO_TEXT_MODEL=mimo-v2.5-pro # 纯文本兜底模型
export PLANT_MIMO_ASR_MODEL=mimo-v2.5-asr  # 语音转写
export PLANT_TTS_MODEL=mimo-v2.5-tts       # 语音合成
export PLANT_TTS_VOICE=mimo_default
```

## 三、完整环境变量表

| 变量 | 默认 | 说明 |
|------|------|------|
| `PLANT_DATA_DIR` | `<代码目录>/data` | 数据目录 |
| `PLANT_DB` | `<数据目录>/plant.db` | SQLite 文件路径 |
| `PLANT_MIMO_KEY` | 空 | 大模型密钥；缺失 → mock |
| `PLANT_AI_MODE` | `auto` | `auto` / `mimo` / `mock` |
| `PLANT_MIMO_BASE_URL` | 见 `config.py` | 模型服务地址 |
| `PLANT_MIMO_MODEL` | `mimo-v2.5` | 多模态主模型 |
| `PLANT_MIMO_TEXT_MODEL` | `mimo-v2.5-pro` | 文本模型 |
| `PLANT_MIMO_ASR_MODEL` | `mimo-v2.5-asr` | 语音转写 |
| `PLANT_TTS_MODEL` | `mimo-v2.5-tts` | 语音合成 |
| `PLANT_TTS_MAX_CHARS` | `120` | 送去合成的最大字数（**音频瘦身关键项**） |

| `PLANT_TOKEN_SECRET` | `plant-demo-secret-change-me` | JWT 签名密钥，**生产必改** |
| `PLANT_DEMO_OPEN` | `1` | 一键演示登录开关 |
| `PLANT_DEMO_CODE` | `123456` | 演示固定验证码 |
| `PLANT_RATE_LIMIT` | `1` | 接口限流开关 |
| `PLANT_UPLOAD_INTERVAL_S` | `60` | 上报节流 |
| `PLANT_AI_DAILY_QUOTA` | `100` | 每日 AI 调用额度 |
| `PLANT_AUTO_WATER_BELOW` | `25` | 自动浇水的水分阈值（%） |
| `PLANT_AUTO_WATER_COOLDOWN_MIN` | `30` | 自动浇水冷却（分钟） |

## 四、代码结构

```
plant_server/
├── run_server.py              启动入口
├── requirements.txt
├── publish_firmware.py        发布 OTA 固件（写元数据 + sha256）
├── backup.sh                  云端备份
├── app/
│   ├── main.py                FastAPI 装配：挂路由、挂静态资源
│   ├── config.py              全部配置与环境变量
│   ├── db.py                  SQLite 访问层（建表/连接/迁移）
│   ├── admin.py               管理台后端（23 个接口，前缀 /admin）
│   ├── security.py / ratelimit.py / utils.py
│   ├── routers/               15 个路由模块
│   │   ai / plants / telemetry / devices / device_bridge / actuator /
│   │   auth / community / insurance / billing / media / tasks /
│   │   events / reports / system
│   ├── services/              11 个业务服务
│   │   ai_gateway（AI 编排核心）/ plant_ops / billing_ops /
│   │   actuator_ops / media_store / audio_util（WAV 重采样）/
│   │   community_seed / demo_plants / seed / service_ctl
│   └── static/
│       ├── admin/             网页管理台（index.html / app.js / style.css）
│       └── mobile/            手机端 PWA + ZhiXiaoBan.apk
├── scripts/                   演示数据重置脚本
└── ota/firmware/              OTA 固件发布目录
```

### AI 网关（`app/services/ai_gateway.py`）要点

| 能力 | 函数 |
|------|------|
| 语音理解（转写 + 回答） | `understand_voice()` |
| 图像诊断 | `image_*` / 看图链路 |
| 文本问答 | `chat_text(..., voice=True)` 时追加语音化提示词、限长、关思考 |
| 语音合成 | `tts()` —— 只念回答、限长、降采样到 16 kHz |
| 演示模式 | 无密钥时自动 mock |

**降级链**：主模型返回空内容或占位文本 → 关思考重试 → 备用模型 → 占位兜底；
对上层始终返回可展示内容，不把空回答推给用户。

## 五、部署到云服务器（阿里云 ECS 实测形态）

| 项 | 值 |
|----|----|
| 代码目录 | `/opt/plant_server` |
| 进程管理 | systemd 服务名 **`plant-server`** |
| 对外端口 | **8011**（安全组需放行） |
| 访问地址 | `http://<公网IP>:8011` |

常用命令：

```bash
systemctl status plant-server
systemctl restart plant-server
systemctl is-active plant-server
journalctl -u plant-server -n 100 --no-pager
```

更新代码：把改动文件同步上去后重启服务。

```bash
# 本机 → 云端（示例）
scp -i <密钥> -r app root@<公网IP>:/opt/plant_server/
ssh -i <密钥> root@<公网IP> "systemctl restart plant-server && systemctl is-active plant-server"
```

> 换服务器地址后，**板卡侧配置也要跟着换**（`/mnt/sd/plant.cfg` 里的 `server_host`），
> 否则板卡会连旧地址、OTA 也会指向旧地址。

## 六、数据与备份

- 运行数据在 `data/`：SQLite 单文件 + WAL。**仓库未收录**（跑起来就会变）。
- 备份：本机直接拷 `data/`；云端用 `backup.sh` 或在 `/opt/plant_server/data` 做在线备份（含 WAL）。
- 重置演示数据：

```bash
python scripts/reset_demo_state.py     # 重置演示状态
python scripts/reset_demo_claims.py    # 重置演示理赔数据
```

---

## 七、发布固件（OTA）

```bash
python publish_firmware.py <固件路径> <版本号>
```

发布后固件落在 `ota/firmware/`，板卡侧用 `plant ota check` 拉取升级（A/B 双槽 + sha256 校验 + 回滚）。

---

## 八、注意

1. **手机端页面就在这个工程里**（`app/static/mobile/`）—— 改手机端界面 = 改服务器代码，改完要同步到云并重启才生效。
2. `app/static/mobile/ZhiXiaoBan.apk` 是"网页下载安装包"用的那一份，与 `mobile/plant_android/build/ZhiXiaoBan.apk` 是同一个文件。
3. 接口默认走 **http**（不是 https），安卓壳里开了 `usesCleartextTraffic` 才能访问。
4. 生产部署务必改 `PLANT_TOKEN_SECRET`、关闭演示开关、开启限流。
