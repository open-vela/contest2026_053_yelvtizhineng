# 05 · 手机端构建

> 实测机型：**华为 Mate70 Pro+**（Android）
> 两种形态、一套界面：**PWA（网页）** + **安卓 WebView 壳**

---

## 一、先分清两个形态

| 形态 | 是什么 | 位置 | 怎么用 |
|------|--------|------|--------|
| **PWA（网页版）** | 手机端**界面本体**，由服务器发出 | `server/plant_server/app/static/mobile/` | 手机浏览器打开 `http://<服务器IP>:8011/mobile/`，可"添加到主屏幕" |
| **安卓壳 APK** | 一个 WebView 外壳，打开就往服务器加载手机端页面；拍照、录音走安卓原生能力 | `mobile/plant_android/` | 安装 `build/ZhiXiaoBan.apk` |

**关键点**：界面内容在服务器上，所以**改界面不用重新发 APK** ——
改 `app/static/mobile/` 里的文件，同步到云并重启服务即可。
只有在"壳本身"要改时才需要重新编 APK：

- 权限声明（相机 / 麦克风 / 网络）
- 原生拍照与原生录音
- 启动页、图标、包名、版本号

---

## 二、直接用 PWA（推荐先试这个）

1. 手机与服务器在同一网络（或直接用云端地址）。
2. 浏览器打开 `http://<服务器IP>:8011/mobile/`。
3. 登录：**短信验证码固定 `123456`**，或点"一键演示登录"。
4. 想要图标：浏览器菜单 →「添加到主屏幕」。

> 换界面后手机还看到旧样子？清一下浏览器缓存，或调一下 `sw.js` 的版本号（Service Worker 离线缓存）。

## 三、安卓工程结构

```
mobile/plant_android/
├── AndroidManifest.xml          包名 / 版本 / 权限 / 组件声明
├── build.ps1                    手工打包脚本（不依赖 Gradle）
├── zxb.keystore                 签名库（口令写在 build.ps1 里）
├── src/com/zhixiaoban/app/
│   ├── MainActivity.java        WebView 壳 + 原生拍照 + 原生录音上传（约 28 KB）
│   └── SimpleFileProvider.java  拍照结果交给 WebView 用的 FileProvider
├── res/                         图标（mipmap-*）、颜色、字符串、主题
└── build/                       产物：base.apk → aligned.apk → ZhiXiaoBan.apk
```

Manifest 要点：

| 项 | 值 |
|----|----|
| 包名 | `com.zhixiaoban.app` |
| 版本 | `versionName="1.2"`，`versionCode="3"` |
| 权限 | `INTERNET`、`ACCESS_NETWORK_STATE`、`RECORD_AUDIO` |
| 其它 | `usesCleartextTraffic="true"`（允许 http 访问局域网/云服务器）、竖屏、硬件加速 |

> `RECORD_AUDIO` 是专为"语音输入"加的：WebView 在 http 页面下拿不到麦克风，
> 所以由安卓原生采音再把音频交给网页。

## 四、重新编译 APK

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File mobile\plant_android\build.ps1
```

脚本流程：`aapt2 compile` → `aapt2 link` → `javac` → `d8` →
把 `classes.dex` 塞进 base.apk → `zipalign` → `apksigner` 签名 → 打印 sha256。

### 环境要求

| 依赖 | 版本 / 位置 |
|------|------------|
| JDK | **17** |
| Android SDK build-tools | **34.0.0**（提供 `aapt2` / `d8` / `zipalign` / `apksigner`） |
| Android 平台库 | `platforms/android-35/android.jar` |
| 目标版本 | `--min-sdk-version 24`，`--target-sdk-version 34` |

> `build.ps1` 里的路径依赖本机 SDK 位置，换机器需要改脚本里的 `$sdk` 等变量。

### 签名

签名库 `zxb.keystore`，别名 `zxb`，口令写在 `build.ps1` 内（V1/V2/V3 都开）。

> ⚠️ **换签名会导致老用户装不上新包**，交付时请保持一致。
> 生产环境务必把口令从脚本里挪到环境变量。

## 六、手机端功能与代码位置

界面逻辑都在 PWA 里（`app/static/mobile/app.js`，约 100 KB）：

| 功能 | 说明 |
|------|------|
| 首页 | 植物状态、关键读数、顶部状态栏 |
| 数据页 | **八参数**：温度 / 水分 / EC / pH / 盐分 / 氮 / 磷 / 钾 |
| 拍照问诊 | 原生拍照 → 上传服务器 → 大模型看图给结论 |
| 问 AI | 文字输入 + **语音输入**（原生录音），**不限话题**（不止聊植物） |
| 多用户 | 注册 / 登录 / 账号管理 |
| 社区 | 发帖、评论、点赞 |
| 一键理赔 | 绿植保险理赔流程（**差异化功能**） |
| 会员订阅 | 档位与权益 |
| 自动守护 | 自动浇水/补光的开关与执行记录 |

## 七、注意

1. 手机与服务器要在同一网络，或直接用云端地址。
2. 服务地址是 **http 而非 https**，所以 Manifest 里开了 `usesCleartextTraffic`；换 https 后可关掉。
3. 权限被拒时拍照/语音不可用 —— 首次使用请在系统设置里允许「相机」「麦克风」。
4. 安卓 9+ 若走明文 http，个别定制系统还要求"允许应用使用明文流量"，遇到就是系统级开关。
