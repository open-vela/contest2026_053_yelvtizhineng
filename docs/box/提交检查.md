## 本次整理

- 应用、板级配置、工具、底层补丁、运行与验证说明分别放在 `app/plant-companion`、`board/box`、`tools/box`、`patches/box`、`docs/box`。
- manifest 保留官方工作区入口，新增独立 BOX 配置映射；已提交无线传感器模块保持独立。
- 采用 fork → PR 的方式提交比赛仓库，保留历史提交。
- 清除开发者凭据、历史录音、调试数据、备份副本和可生成的大体积原始字体；保留构建必需的模型 C 数组、第三方静态库及其来源与许可。
- 原工程 Apache-2.0 声明保留。Noto、OpenMoji、ESP-SR、ESP-DSP、newlib 和 cJSON 等第三方内容依各自许可，不能统称为自研 Apache 源码。特别是 OpenMoji 衍生字形保留 CC BY-SA 4.0，ESP-SR 使用范围受其产品许可限制。见根目录 `NOTICE` 和 `licenses/`。
- BOX 选定开发会话的645条用户可见真实对话，通过官方事件格式和校验器导出；沿用原始时间戳，提交前按官方机制脱敏，不上传非公开通道、原始工具记录或其他会话。开发不在 `.repo` 工作区，故如实标注人工选择导出，不能声称自动采集闸门已通过。原始快照只在本机私有审计目录。

## 仍需独立核对的官方要求

1. 此固件实际建立在同事的固定 DVP 参考提交及后续本地 SDK 改动上，而非已完成官方 `dev-ai-contest-2026` 合入的纯净 SDK。`patches/box/baselines.json` 提供精确来源及校验值。补丁的提交不等于公共 NuttX/apps PR 已被组委会审核或合入；公共仓改动应另按官方要求移植、测试并提交 PR。
2. 现有应用采用独立的设备端编排与云端协议路线。此次只整理现有固件，未新增或验证 ai_agent 运行时以及 `/data/agent/skills/` 下的自定义 Skill；不把普通 C 指令表写成已完成的 ai_agent Skill。赛道“主动+执行”和 Skill 的形式化验收仍应以组委会要求和实际演示为准。
3. 独立编译使用已固定版本的下载缓存，没有把一次完整联网 `repo sync` 的验证记为已完成。公开构建产物未在本次整理中重新刷入设备。

上述边界不隐藏在宣传数据中，也不会通过伪造日志、空 Skill 或改写既有测试结果来补齐。
