# BOX v1.3.239 版本与验证

## 本次源码对应的行为

- 统一“小伴”首页文案，豌豆角色随待机、收听、思考和说话切换表情；更多页采用图标入口，修复配网键盘最后一排大写显示。
- 采用同事 DVP 优化的参考代码，完成 BOX 的预览、JPEG 拍照、缓存与音频并发适配。现场预览约 12 FPS，不能将外接拍摄摄像头帧率当作设备预览帧率。
- 复用 MultiNet5 Q8 中文模型处理已唤醒状态的常用控制，低置信度回退云端。唤醒保留宽松判断，支持常见同义说法和否定撤销，不是本地大语言模型。
- 修复反复重建词表引起的内存增长、相机退出后未恢复收听、土壤页面返回行为，以及无内容短音触发长问答。
- 云端普通语音加本地柔化处理；停止使用慢且易超时的额外童声合成路线。
- 土壤状态读取独立无线传感器的云端数据，按五分钟周期拉取；不存在通过 BOX 共用摄像头引脚直接读取当前无线节点的接线要求。

## 能力边界

常用指令理解优先在端侧，开放问答、植物视觉识别、语音合成和传感器云端读取仍依赖网络。只有在设备说完后再说下一句；噪声、音量、距离和不同表达仍会影响识别。养护任务确认与观察记录属于交互闭环，当前 BOX 没有已接入的实际浇水执行机构。
