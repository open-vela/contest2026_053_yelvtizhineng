# ESP32-BOX v1.3.239 运行指南

本指南对应当前豌豆外壳 BOX，ESP32-S3、16MB Flash、8MB PSRAM、OV3660 摄像头及 480×320 屏幕。无线土壤节点独立运行，见 [soil-node](../soil-node/运行指南.md)。M5 适配不属于本次 BOX 源码更新。

## 取得源码与依赖

官方比赛仓库入口保留 `dev-ai-contest-2026` 分支和 manifest 中的应用、板级配置映射。应用在 `app/plant-companion`，配置在 `board/box/configs/contest_v239`。官方分支不包含本次所需的全部 DVP、音频和内存改动，不能只同步官方 SDK 就宣称可复现该固件。

为复现已验证的硬件行为，先建立独立参考 SDK，固定同事相机分支的提交；这些参考提交属于依赖来源，并不代表它们已合入 openvela 官方仓库：

```bash
mkdir box-sdk && cd box-sdk
git clone https://gitee.com/yang-asjdsad/nuttx.git nuttx
git -C nuttx checkout 287b4b51aea0b428a5bcbc0c8835f5bd692e9c19
git clone https://gitee.com/yang-asjdsad/nuttx-apps.git apps
git -C apps checkout 8986d35eb230779a28da793a9220148a8cb18072
git clone -b dev-ai-contest-2026 https://github.com/open-vela/contest2026_053_yelvtizhineng.git contest
```

建议使用 Ubuntu/Linux，安装 GNU make、Git、Python 3、kconfiglib、flock、esptool，以及 `xtensa-esp32s3-elf` GCC 12.2.0 工具链，并将工具链 `bin` 放入 PATH。依赖版本和每个底层文件的前后校验值见 `patches/box/baselines.json`。Espressif HAL 固定在 `9fc713a95b1ff150dd0b0647e465d3c624056bb1`，其他标准库由 NuttX 构建规则获取。

## 预检与编译

```bash
python3 contest/tools/box/prepare.py . --check
bash contest/tools/box/build.sh .
```

预检不修改文件；基线不同会停止。应用准备阶段会备份已有同名应用目录、受影响底层文件和 `.config`，应用补丁，建立应用/配置链接并安装配置。不要把 BOX 补丁套到无线土壤节点工作区。

产物为 `nuttx/nuttx.bin`。构建后检查内部启动堆余量和 4 MiB 应用大小上限。公开配置不含开发者 API Key、WiFi 密码或设备 token，因此与此前真机私有配置构建的二进制校验值可能不同。

## 烧录

当前已验证设备使用单应用分区：`0x10000` 起，长度 `0xB00000`。本版本不能按历史 README 的 2MB 双槽方式烧录，也不能向 `0x210000` 再写一次。

```bash
python3 -m pip install esptool
python3 contest/tools/box/flash.py --port COM23 --image nuttx/nuttx.bin --write
```

工具先读取实际分区表；只有匹配的单应用布局且镜像不超过已验证 4 MiB 上限才写入 `0x10000`。不会写 bootloader、分区表或用户数据。COM23 只是示例，应选实际设备串口。全新设备需要先具备与该硬件兼容的启动程序和上述分区布局；此工具不承担出厂初始化。

## 配置与运行

1. 开机后在“更多 → 网络”选择 WiFi 并输入密码，大小写键盘已修正。
2. 使用自己的云端部署或获授权的 `api.seesoil.com` 服务完成设备注册与传感器绑定。凭据存运行配置，不写入源码。本仓不包含线上设备 token。
3. 当前配置存 `/data/plant.cfg`，旧 SD 配置仅用于兼容读取。云端土壤数据按 300 秒周期拉取，界面保留采集时间，过期和缺失读数不作为实时测量。
4. 说“你好，小伴”，等回应结束后再说“打开相机”“帮我拍照”“回到首页”“查看状态”“土壤湿度是多少”“打开成长日记”等。
5. 相机对准叶片、保持补光。预览、JPEG 拍照与识图是不同阶段；识图和自由问答仍需网络。当前未启用播报中插话打断。

仓库已另外整理主业务 API、手机网页/PWA、独立 BOX AI 服务与 JSON 土壤网关源码，部署入口见 [服务器说明](../../server/README.md)，验证范围见 [服务器来源与验证](../server/来源与验证.md)。Android 原生工程仍为此前版本。使用自己的部署时需配置设备注册、鉴权与传感器绑定；源码整理不代表已在新环境完成部署验收。
