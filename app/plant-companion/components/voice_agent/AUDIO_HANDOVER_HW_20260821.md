## 1. 硬件平台（请以此为准）

| 项 | 值 |
|----|-----|
| 主板 | CHD-ESP32-S3-BOX V2.0（与 xiaozhi esp-box-3 同款电路） |
| SoC | ESP32-S3（内置 USB-Serial-JTAG，16MB flash，8MB PSRAM） |
| ADC 码片 | **ES7210**（4 通道 ADC，I2C 0x40，从模式） |
| DAC 码片 | **ES8311**（I2C 0x18，从模式） |
| 功放 | NS4150B（GPIO46 使能，高电平开） |
| 麦克风 | **MSM381A3729H9CP**（MEMS，模拟输出，-38dBV/Pa @1kHz，VDD 1.5-3.6V，DC 输出 0.7V）|
| 麦克风数量 | 2 颗（MIC1/MIC2），接 ES7210 MIC1P/N、MIC2P/N |

### I2S0 引脚（关键）

| 信号 | GPIO | 方向 | 说明 |
|------|------|------|------|
| MCLK | GPIO2 | ESP32→码片 | 160MHz/26 = **6.154MHz**（整数分频，零抖动） |
| BCLK | GPIO17 | ESP32→码片 | MCLK/4 = **1.539MHz**（TX 输出 + matrix_in 回环给 RX） |
| WS | GPIO45 | ESP32→码片 | BCLK/64 = **24.04kHz**（同上回环） |
| DOUT | GPIO15 | ESP32→ES8311 | TX 数据 |
| DIN | GPIO16 | ES7210→ESP32 | RX 数据（ES7210 SDOUT1 → R25(10Ω) → R96(0Ω) → GPIO16）|
| PA | GPIO46 | ESP32→NS4150B | 功放使能 |

I2C 共享总线：ES8311@0x18、ES7210@0x40、GT911 触摸、IMU、摄像头（均有总线锁，多外设共存安全）。

### 麦克风供电与输入通路（原理图核实）

- **麦克风 VDD = ADC_VCC33（3.3V 直供）**，不依赖 ES7210 的 MICBIAS。
- 麦克风 OUT → ADC_MIC1P/ADC_MIC2P（ES7210 差分正输入）；MIC1N/MIC2N → GND（R67/R69 0Ω）。
- ES7210 MICBIAS12/34 走 R68/R70 网络（麦克风供电不靠它，但寄存器已配 2.87V）。
- ES7210 输入侧：MCLK(6.154MHz)、SCLK、LRCK 由 ESP32 I2S0 提供；SDOUT1 输出 4 通道 TDM。

### ES7210 关键寄存器配置（当前固件，mictest 读回确认）

```
REG00=0x41 复位后 | REG01=0x20 4麦时钟 | REG02=0xc1 DLL+doubler
REG06=0x00 非掉电   | REG07=0x20 OSR    | REG08=0x10 slave+LRCK_RATE_MODE=1
REG11=0x60 16bit I2S| REG12=0x02 TDM    | REG14/15=0x00 非静音
REG20=0x0a 21=0x2a 22=0x0a 23=0x2a（HPF，与 IDF 一致）
REG40=0x43 模拟电源+VMID | REG41/42=0x70 MICBIAS 2.87V
REG43-46=0x16 增益18dB    | REG47-4A=0x08 麦电源 | REG4B/4C=0x00
```

## 2. 问题现象（用户可复现）

1. **录音回放听不到清晰人声**：对着麦克风说话，回放里只有微弱"人声轮廓"，被噪声盖住；用户描述为"收音机开机那种吃啦/兹啦声"。
2. 静音时回放基本安静（软件处理后），但说话声也几乎听不见。
3. 播放 440Hz 音调正常（DAC 链路 OK）。

## 3. 已确认的事实（数据证据，勿重复排查）

### 3.1 数字通路全部正常
- **RX 速率 = 190~198KB/s = 4 槽 × 24.04kHz = 96k 采样/s**（多次实测稳定）——交接文档里"157k 采样/s = 1.64× 过采样"的结论**不成立**（是旧固件误读）。
- I2S 时钟配置回读正确：MCLK=6.154MHz、BCLK=1.539MHz、WS=24.04kHz（整数分频零抖动）。
- DMA 收发、中断、信号量全部工作（rate 测试 0 超时）。

### 3.2 ES7210 能拾音（echo 测试铁证）
- 新增 `plant voice echo` 测试：播放 1kHz 音调 41.6ms **同时**录音（`hal_i2s_write_read_sync`）。
- 结果：RX **过零=388 次、能量巨大** → 录音里出现强 1kHz 信号 → **ES7210 模拟通路 + 麦克风拾音是通的**。
- 播放音调时 RX 满幅（RMS~10000+）——**声学耦合或数字串扰都说明信号能进来**。

### 3.3 说话时信号确实变化
- mictest（单槽槽0）：静音时 |s| 99.99% <100；说话时 100-999 档从 6 个跳到 **11063 个**（550×）。
- 18dB 增益下说话信号理论上应到 800-8000 LSB。

### 3.4 已定位并软件绕开的噪声源
1. **REG40 LDO/VMID 被 MCLK 启动清掉**（0x43→0x42）：ES7210 在无 MCLK 状态初始化，MCLK 启动后 bit0(LDO_EN) 丢失 → ADC 输入共模错误 → **确定性极限环噪声（麦克风无声的根因）**。已修复：MCLK 启动后 `es7210_restore_analog()` 重写并验证。
2. **每次 RX 重启的开头瞬态**（HPF 阶跃响应，实测 -32767~+30720 起振荡）：每块丢弃开头 128 采样。
3. **每块末尾（~864-999 区间）约 21-41 个大值噪声**：丢弃末尾 160 采样。
4. **68.7Hz 周期脉冲**：见 §4.2。
5. **录音 4 槽流带 DC 阶跃/确定性尖峰**：录音改用**单槽路径**（只收 MIC1），数据明显干净。
6. **HPF 寄存器地址写反**（REG22/23 与 IDF 相反）：已修正。
7. 增益 18dB（原 9dB 下人声太小）。

### 3.5 当前录音处理链（软件，已烧录）
```
单槽48k流 → 每块丢开头128+末尾160采样 → 3:1平均(→16k)
→ 高通220Hz(α=1/16) → 11点中值(消脉冲) → 低通5kHz(α=0.86)
→ 限幅±4000 → 噪声门|s|<80归零 → WAV 16kHz
```
静音基线：峰值 472、残留尖峰 0、均值 0 —— **静音已干净**。

## 4. 卡住的疑点（需要硬件/系统测量定性）

### 4.1 疑点 A：说话声信号弱 / 听不清人声（最优先）
- **现象**：静音干净，但说话时回放听不清（用户"还是不行"）。
- **已排除**：数字通路（速率/时钟/DMA 全对）、ES7210 拾音（echo 测试通）、静音底噪（已滤）。
- **剩余可能**：
  1. 麦克风实际灵敏度不足 / 拾音位置差（板载 2 麦离喇叭近，声学耦合反而大于人声？）。
  2. **ES7210 输入增益路径问题**（MIC1 PGA 是否真正放大？REG43-46=0x16 读回确认过，但实测说话信号峰值仅几百 LSB，与 18dB 预期 800-8000 不符）。
  3. 说话 vs 播放的耦合强度差异（播放时满幅、说话时几百——可能是喇叭声直接耦合进 MIC 而非麦克风正常拾音）。
- **需要测量**：
  - [ ] 万用表/示波器：**麦克风 VDD（ADC_VCC33 处）≈3.3V**、**OUT 静态 DC ≈0.7V**（无说话时）。
  - [ ] 示波器（×10 探头，AC 耦合）：**IO16(DIN)** 在【对麦克风说话】时是否有明显 AC 波形（幅度 vs 静音）。
  - [ ] 示波器：ES7210 **MIC1P 引脚**说话时波形（确认信号到达码片输入）。
  - [ ] 对比：用手按住麦克风出声孔 vs 放开，DIN 信号是否变化。

### 4.2 疑点 B：68.7Hz 周期脉冲（"兹啦"声源，软件已掩盖但根源未明）
- **现象**：静音录音里每 **14.56ms**（68.7Hz）一组 4-5 个连续大值（2000-4000 LSB），贯穿全程；11 点中值已消除听感，但根源未定。
- **已排除**：LCD 刷新（禁用 LCD 后脉冲反而增大 12 倍）、tick 定时器、TX silence 环周期（2.66ms）。
- **剩余可能**：
  1. **电源纹波/开关噪声**（68.7Hz ≈ 某 DC-DC 频率或其分频）。
  2. **ES7210 内部时钟分频毛刺**（内部 MCLK 12.308MHz 的某个分频）。
  3. PCB 上 BCLK/WS/DOUT 与 DIN 的串扰（BCLK 1.539MHz 的 22400 分频 ≈ 68.7Hz？1.539M/22400=68.7——**22400 恰好是 56×400，可疑但非整数关系**）。
- **需要测量**：
  - [ ] 示波器：**ADC_VCC33 / VDDA 纹波**（是否有 68.7Hz 成分）。
  - [ ] 示波器：**IO16(DIN)** 在【静音、TX 静音环运行】时的波形——是否看到 14.56ms 周期的毛刺。
  - [ ] 若方便：**断开 ES7210 SDOUT 链路**（R25 一端悬空），DIN 浮空时看 RX 是否还有脉冲（区分 ES7210 输出 vs PCB 串扰）。
  - [ ] 换一个 ES7210 芯片/板子对比（排除个体差异）。

### 4.3 疑点 C：4 槽 RX 流的 DC 阶跃与确定性尖峰（录音被迫用单槽）
- 4 槽全采流（rate 测试可见）带起始 DC 阶跃（+12800 衰减）和确定性尖峰（16657/8531/1609/2 恒定图案，每次相同）。
- 录音已改单槽（只收 slot0=MIC1）绕开，但**单槽流也非完全干净**（仍有 68.7Hz 脉冲）。
- 需硬件确认：ES7210 4 通道 TDM 输出（64bit/帧）与 RX 采样是否完全对齐（若有 1 采样错位 → DC/尖峰）。

## 5. 需要同事做的（按优先级）

### 硬件测量（万用表 + 示波器，约 30 分钟）
1. **量 3 个电压**：麦克风 VDD≈3.3V、麦克风 OUT 静态≈0.7V、ES7210 ADC_MICBIAS12≈2.87V。
2. **示波器看 DIN(IO16)**：静音 vs 说话 vs 播放音调，三态对比——确认麦克风声学信号真实到达。
3. **示波器看 68.7Hz 脉冲**：IO16 或 VDDA 纹波，找周期源。
4. **说话对比**：对麦克风喊话，看 DIN 波形幅度（预期人声应 ~几十 mV 级 × PGA）。

### 软件侧（如果硬件确认通路正常）
- 若 DIN 说话波形正常但录音仍小 → 查 ES7210 增益寄存器实际生效（REG43-46 逐位读回 + 试 30dB 最大增益）。
- 若 DIN 说话波形本来就小/没有 → 麦克风供电/偏置/焊接问题（硬件）。

## 7. 当前固件改动清单（本轮，全部编译烧录验证）

| 文件 | 改动 |
|------|------|
| `es7210.c/h` | REG40 LDO/VMID 恢复函数 `es7210_restore_analog()`；HPF 寄存器地址修正；增益 18dB；RESET 后补全重配 REG42/44-46/48-4A |

| `ai_voice.c` | 录音改单槽+3:1降采样；每块丢开头128/末尾160采样；高通220Hz；11点中值；低通5kHz；噪声门；`ai_voice_echo_test()`；段峰值/尖峰诊断 |
